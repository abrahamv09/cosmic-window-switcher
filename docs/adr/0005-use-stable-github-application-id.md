# Use io.github.abrahamv09.CosmicWindowSwitcher as the application ID

The project will live at `abrahamv09/cosmic-window-switcher`, and its desktop entry, icon, D-Bus service, COSMIC configuration namespace, and related package metadata will use `io.github.abrahamv09.CosmicWindowSwitcher`. The reverse-DNS identifier is anchored to the maintainer’s verified `abrahamv09` GitHub namespace and must remain stable so upgrades continue to find existing user configuration and services.
